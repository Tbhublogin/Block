### 2. `lib/domain/models/piece.dart` — one tray piece / shape definition (PRD §5.2, §11)
```dart
class Piece {
  final String id;                  // PRD §11 id
  final List<List<bool>> shapeMatrix; // rectangular, ≥1x1; [[true]] for the special piece
  final bool isSpecial;             // true = line/column clear piece (AI_RULES 16/17)
  final String landmarkId;          // reference key ONLY — no asset path, per request

  const Piece({required this.id, required this.shapeMatrix, this.isSpecial = false, required this.landmarkId});
  const Piece.special({required this.id, required this.landmarkId})
      : shapeMatrix = const [['true' → true]], isSpecial = true;  // 1x1 [[true]]

  int get rows => shapeMatrix.length;
  int get cols => shapeMatrix.first.length;
  int get filledCellCount => count of true cells;   // engine scoring may need per-cell counts
  // == / hashCode: deep matrix equality + id + isSpecial + landmarkId
  // toString()
}
```
Constructor asserts (debug-only, no runtime cost in release): matrix non-empty, rectangular, all rows same length; and `isSpecial` ⇒ exactly 1×1. These invariants protect the board engine from malformed shapes.
