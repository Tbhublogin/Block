# Phase 1 (BUILD_PROMPTS 0.2): Localization System

## Approach decisions
- **gen-l10n non-synthetic configuration** (Flutter's current recommended style): generated sources go to `lib/l10n/generated/` and are imported via `package:block_civilizations/l10n/generated/app_localizations.dart`. This avoids the deprecated `flutter_gen` synthetic package (relevant on Flutter 3.47). If `synthetic-package: false` is rejected/warned by this Flutter version, drop that key and rely on `output-dir`.
- **Locale with no cold-start flash**: `main()` preloads `SharedPreferences` before `runApp` and injects it via a `sharedPreferencesProvider` override, so `languageProvider` resolves synchronously on the first frame (no Arabic→English flash for English users). `languageProvider` is a Riverpod `Notifier<Locale>` defaulting to `ar`; `setLanguage()` updates state instantly (PRD §7: no restart) and persists to prefs.
- **Extra ARB key** `underConstruction`: moves the hardcoded 'Under construction' string out of `app.dart` per AI_RULES #6 and PROJECT_STATE next-steps. The 4 requested strings (appTitle, mainMenuPlay, mainMenuMuseum, mainMenuSettings) are added exactly as specified; mainMenu* stay unused until the Main Menu screen phase.
- Arabic is the template ARB (`app_ar.arb`), matching "Arabic default".

5. **Run `flutter gen-l10n`** → generates `lib/l10n/generated/app_localizations.dart` (+ `_ar`/`_en` variants). These generated files are committed (not gitignored) so analyze/tests work on fresh clones; they auto-regenerate on every `flutter run/test/pub get` via `generate: true`.

6. **lib/application/settings_controller.dart** (replace stub):
   - `sharedPreferencesProvider` = `Provider<SharedPreferences>` throwing `UnimplementedError()` by default, overridden in `main`.
   - `languageProvider` = `NotifierProvider<LanguageController, Locale>`; `build()` reads `settings.languageCode` from prefs, validates against `{ar, en}`, defaults to `ar`.
   - `Future<void> setLanguage(Locale)` — sets state immediately + persists `locale.languageCode`.

7. **lib/main.dart** — `main()` becomes async: `WidgetsFlutterBinding.ensureInitialized()`, await `SharedPreferences.getInstance()`, `runApp(ProviderScope(overrides: [sharedPreferencesProvider.overrideWithValue(prefs)], child: const App()))`.

8. **lib/app.dart** — `App` becomes a `ConsumerWidget`:
   - `locale: ref.watch(languageProvider)`
   - `supportedLocales: AppLocalizations.supportedLocales`
   - `localizationsDelegates: AppLocalizations.localizationsDelegates` (includes App + GlobalMaterial/Widgets/Cupertino delegates)
   - `onGenerateTitle` returning localized `appTitle` (keeps AI_RULES #6 — no hardcoded user-facing strings)
   - `_PlaceholderScreen` uses `AppLocalizations.of(context).appTitle` / `.underConstruction`; theme unchanged.
   - MaterialApp automatically derives `Directionality` from the locale → RTL under Arabic.

9. **test/widget_test.dart** — rewrite smoke test:
   - Helper `pumpApp(tester, {prefsValues})`: `SharedPreferences.setMockInitialValues(...)`, pump `ProviderScope` with the prefs override, then `pumpAndSettle()` (localizations load).

   - Test 2: pref `settings.languageCode: 'en'` → English strings, `TextDirection.ltr`, locale `en`.
